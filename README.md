# 故土与新途：乡村小学的撤并倒计时

徐皓萱 / Hazel Xu 的本科毕业设计移动端交互报道。

**[阅读正式作品 →](https://xu-125.github.io/rural-school-countdown/)** · [返回个人作品集](https://xu-125.github.io/portfolio/)

## 作品结构

- **数据与政策**：拖动年份，查看乡村小学数量变化与政策阶段。
- **地方故事**：呈现不同地区乡村学校的处境。
- **人物声音**：点击名片，展开语录。
- **讨论视角**：把撤并、保留与公共生活的问题放在一起看。

本仓库对应可直接浏览的正式移动专题。账号中同主题的其他仓库保留历史探索，不作为这一入口的替代版本。
